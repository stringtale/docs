## When are text edits applied?

Text edits get applied when you pull the changes to your local source code with the [CLI](/reference/cli/#pull) or merge a pull request from the [GitHub Action](/usage/github-action/).
After that, they'll appear in your deployed environments with your next release.

## Can I use rich-text formatting with Stringtale?

Yes, there are various formatting options available. See the [React documentation](/front-end/react/) for examples.

## Can I use string interpolation with Stringtale?

Yes, Stringtale is compatible with string interpolation. Interpolation uses [ICU MessageFormat](https://formatjs.io/docs/core-concepts/icu-syntax/) (via FormatJS / `Intl.MessageFormat`).
You can find more about how to use this in the [React documentation](/front-end/react/).

## Why should I use it on my test / preview environment rather than production?

The Stringtale integration authenticates with the server using an [API key](/usage/obtaining-api-key/). By default, anyone who can access your
test / preview environment can edit text. Therefore it's recommended that you use a secured test / preview environment to avoid unauthorized usage.
On production, omit `STRINGTALE_API_KEY` so the integration stays disabled.

You can also require editor logins by enabling login on your API key, for more information see the [browser extension](/usage/browser-extension/#optional-enable-login) guide.

<Aside type="tip">You can secure your test / preview environment using basic auth.</Aside>

## Is Stringtale open source?

Stringtale is partially open source. The framework integrations, the CLI and the GitHub Action are open source
(see [github.com/stringtale](https://github.com/stringtale)). The back-end server however is proprietary.
